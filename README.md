# Judges_tower
Created December 2024
A three-strikes counter for up to four players for judge's tower or any other strike based game. 
A strike is initiated by pressing the black center button, which blinks everyone's lights. Then a player's button is pressed to give that player a strike. Once a player has 3 strikes, their 3 leds and the light bar all turn off.
